Michigan Traffic by the Numbers

Michigan drivers log nearly 100 billion miles a year and have about 290,000 reported crashes. This dashboard breaks them down by county, by time of day, and by type, including Michigan's one-in-five crashes with a deer. Every number comes from SQL queries over the state's published crash reports.

How it works

  1. The source is the state's own reports. Michigan State Police and Michigan Traffic Crash Facts (run with the University of Michigan) publish crash tables every year. The tables this dashboard uses are saved as CSV files in the repository, each with its source listed.
  2. A Python script loads them into a SQLite database with a defined schema: one table per report, keyed by year and county.
  3. Data checks run first. County totals have to add up to the statewide totals, severity and road-type counts have to add up to each county's total, and every county has to match across all four county tables. If any check fails, the build stops and nothing is published.
  4. SQL does the analysis: joins across years and tables, rates per 1,000 residents, rankings with window functions, five-year averages, and a calendar built with a recursive query to get crashes per day by weekday.
  5. The results go into one JSON file, and this page draws the map, charts and tables from it in the browser. New data arrives once a year (each August), so updating means adding that year's tables and running the script again.

Counts are police-reported crashes on public roads in Michigan. County rates use July 2024 Census population estimates, so counties with lots of visitors (Mackinac, for example) show high rates relative to the people who live there. The 2025 county figures are from the Michigan State Police year-end county report; 2024 county and deer figures are from Michigan Traffic Crash Facts.

Data: Michigan State Police Criminal Justice Information Center; Michigan Traffic Crash Facts (Michigan Office of Highway Safety Planning and the University of Michigan Transportation Research Institute); U.S. Census Bureau population estimates via the Michigan Senate Fiscal Agency. County boundaries: U.S. Census Bureau. This page is an independent project and is not affiliated with any of these organizations.
