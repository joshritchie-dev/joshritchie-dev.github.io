US Economy Thermometer

Where the U.S. economy stands right now, in ten numbers. Everything on this page refreshes automatically every morning from the Bureau of Labor Statistics and the Federal Reserve's FRED database.

Loading the latest data…

How it works

  1. A scheduled job runs every morning on GitHub Actions, shortly after the 8:30 AM Eastern time when BLS publishes new numbers.
  2. A Python script asks BLS and FRED for the latest figures in a single batch request per source, using API keys stored as encrypted secrets, never in the page.
  3. It turns raw series into the numbers people quote: price indexes become year-over-year inflation, total payrolls become jobs added each month, and daily rates are trimmed to one point per month for the charts.
  4. It writes one small data file and saves it back to the site. If a source is down, the last good value stays up and is marked as not updated, so the page never goes blank.
  5. This page reads that file, so it loads instantly and never spends the data providers' request limits on visitors.
