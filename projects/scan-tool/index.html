Paper-to-Sprite Scan Tool

An artist draws animation frames on printed sheets. This tool turns a scan or phone photo of those sheets into clean, aligned sprites with transparent backgrounds, with no image editing by hand.

Source code
Built with
Python, Pillow, NumPy, SciPy, PyMuPDF
Input
Scans, phone photos, or PDFs
Output
Sprite strips, settings file, and a preview GIF
Tests
18 checks on simulated scans and photos

How it works

  1. Printable sheets. The tool generates the paper templates. Each page has corner marks and a small dot code that says which animation and page it is.
  2. Find and straighten. It locates the corner marks, works out which way is up, and flattens the page, including angled phone photos.
  3. Clean up. It evens out lighting, removes the light-blue guide lines, and drops dust and smudges while keeping faint pencil that belongs to the drawing.
  4. Cut out. It builds a transparent background with soft edges and no white halo.
  5. Align. Every frame is placed on the same ground line at the same scale, so the animation doesn't jitter.

Why I built it

The goal was to let someone who draws on paper get a character into the desktop companion in a few minutes. The whole process is: print, draw, scan, drag the folder onto one file.
